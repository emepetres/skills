# Derived skills keep their upstream license

The repository root is MIT under Javier Carnero. A skill derived from another repository preserves that upstream license and copyright notice **inside its own skill directory**, and names the source at the top of its `SKILL.md`.

Relicensing derived work as MIT wholesale is not ours to do, and refusing derived skills outright would rule out the most useful source of material. Per-directory licensing is the narrowest option that keeps both.

## Consequences

- A root `LICENSE` reading MIT does **not** imply MIT for every path in the repo. Check for a `LICENSE` inside a skill directory before reusing or relicensing its contents.
- No skill currently exercises this — there are no per-skill `LICENSE` files today. It is recorded now because the moment it matters is the moment the mistake becomes public and unpublishable.
